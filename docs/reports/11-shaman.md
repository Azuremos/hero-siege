# Сессия 11 — Шаман

Версия 0.14, ветка `shaman` (отдельный worktree `HeroSiege-shaman`, перебазирована на свежий main), тег `v0.14` — локально.

## Сделано

1. **Класс Шаман** (`classes_data.gd`, `spells/shaman.gd`, `talent_data.gd`, `spell_effects.gd`).
   - Ресурс — мана. Расы — дворф и дреней: поле класса `races`, в меню остальные расы серые, сервер подменяет недоступную расу (`ClassData.fix_race`).
   - **Базовые заклинания (6):** Молния, Волна исцеления, Огненный шок, Пронизывающий ветер (прерывание), Тотем жара, Щит молний.
   - **Книга — 9 рядов по 3 варианта**, столбец = ветка: Выброс лавы / Удар бури / Быстрина; Гром и молния / Призрачный волк / Благосклонность предков; Цепная молния / Тотем магмы / Цепное исцеление; Ледяной шок / Тотем оков земли / Сглаз; тотемы гнева воздуха / неистовства ветра / исцеляющего потока; Астральный сдвиг / Ярость шамана / Щит земли; Землетрясение / Кольцо огня / Целительный ливень; Покорение стихий / Героизм / Тотем прилива маны; пассивы Перегрузка / Оружие языка пламени / Пробуждение предков.
   - **Таланты:** три ветки по 8 талантов. Вершины: Стихии — Тотем гнева, Совершенствование — Дух дикого зверя, Исцеление — Тотем целительного прилива.
   - **Проки:**
     - **Волна лавы** — со сбросом перезарядки, как Огненная глыба: талант даёт Извержение лавы, любой удар огнём, включая каждый тик Огненного шока, может его сразу восстановить;
     - Оружие водоворота, Неистовство ветра, Волны прилива, Ясность стихий;
     - пассивы мастерства: Перегрузка, Оружие языка пламени, Пробуждение предков.
2. **Тотемы** — одна система без нод и физики на сервере: зона со стихией (`delivery: totem`).
   - По одному тотему каждой стихии на шамана, новый заменяет старый.
   - Бьют лучом (`shoot`) или по площади, лечат, дают баффы, которые продлеваются, пока союзник рядом.
   - По сети и игроку, вошедшему посреди партии, приходят как обычные зоны. Облик — резной столб с маской и наконечником цвета стихии, из примитивов.
3. **Новые общие механики данными:**
   - `crit_if` — Выброс лавы по цели с Огненным шоком всегда критует;
   - `procs` у dot — тики считаются попаданием для проков;
   - `mana_pct`;
   - баффы `thorns` (Щит молний) и `heal_on_hit` (Щит земли);
   - `cast_move` в BUFF_INFO — каст на ходу, проверяют и сервер, и клиент;
   - `from_totems` — Кольцо огня бьёт и из каждого тотема;
   - флаги `totem_power` / `totem_dur`;
   - поля класса `default_weapon` / `default_offhand`, `melee_trees`;
   - у эффекта `pulse` — свой `vfx`.
4. **Вещи** (`item_data.gd`).
   - Новые шаблоны: тотемный молот, посох бури, щит предков, кольчуга стихий, шапка духов.
   - Шаман носит ещё булавы, посохи, щиты (и священный щит), топоры, мечи и двуручные мечи — по просьбе пользователя.
   - В пустой руке — тотемный молот.
5. **Сеты и легендарки** (`set_data.gd`).
   - Сеты: Повелителя Бури, Духа Волка, Хранителя Приливов.
   - Легендарки: Посох Повелителя Молний, Молот Бури Предков (сбрасывает Удар бури), Щит Бездонного Прилива.
6. **Иконки:** 37 заклинаний, 20 талантов и 5 вещей — свои, с game-icons.net (CC BY 3.0). Проверено, что ни одна не совпадает с уже используемыми. Источник каждой — в `assets/icons/LICENSE.txt`.
7. **Бот-шаман** (`player_controller.gd`).
   - Лечит: Быстрина, Волна, ливень под раненого, тотемы воды. Бьёт: Молния — издалека в любой ветке, по просьбе пользователя.
   - Совершенствование подходит к цели.
   - Тотемы ставит по стихиям, когда тотема нет и он нужен; тотемы стоят в очереди выше заполнителя.
8. **Просьбы пользователя по ходу сессии:**
   - **подсказки непрозрачные** — тёмная подложка с золотой рамкой (`SpellIcon.style_tooltips`, в теме меню и боя);
   - **лечение и щиты на питомца охотника** — клиент считал союзником только героя, и лечение уходило на себя. Теперь питомец в цели, под курсором или на полоске в рамке группы — союзник; у полоски есть «лечение по наведению»;
   - **книга жреца** — без левой вещи жрец держит том в кисти, как маг с надетым томом (`default_offhand`), а не раскрытую книгу у бедра;
   - **сравнение с надетым** — в подсказке вещи из сумки, лавки и обмена: ▲/▼ по характеристикам относительно вещи в той же ячейке. `GameData.tooltip_equip` заведён ещё в 07б, но нигде не заполнялся — теперь его ставят окно персонажа, лавка и обмен.

## Не сделано / нужен ассет

- **Модель шамана** — перекрашенный варвар KayKit. Шапка духов — медвежья шапка варвара. Нужен ассет: маска или шлем шамана.
- **Модель тотема** — из примитивов. **Призрачные волки** Духа дикого зверя — только вихрь частиц. Нужны модели.
- **Звуки** молнии, грома и тотема — пока из имеющихся (arcane, fire_big, trap_set). Нужен ассет.
- Тотемы нельзя разбить врагами (см. DECISIONS).
- Сравнение вещей — строками в той же подсказке, а не второй подсказкой рядом, как в WoW. Особые свойства надетой вещи (прок, сет, легендарка) только упомянуты.
- Нативную всплывающую подсказку не удалось вызвать в тестовом снимке синтетической мышью. Снимок `11-tooltip.png` показывает её стиль (`TooltipPanel` / `TooltipLabel`) на панели.
