# Сессия 09 — наёмники для одиночной игры, правила добычи, трупы с добычей

Перед началом прочитай `CLAUDE.md`, `README.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md`. Нужна 04б (вещи-экземпляры с качеством). Желательна 03 (боссы).

---

## 1. Наёмники

Бот уже играет всеми классами: ротация, прерывания, уход из телеграфов, выбор в книге по ветке. Используем его как союзника.

- **Где нанять.** В замке — новый NPC «Капитан наёмников» или казармы. Наёмник стоит золото: разово плюс плата за волну, если решишь. Не больше 5 союзников в отряде (герои + наёмники ≤ 6).
- **Выбор:** класс и роль (танк, лекарь, урон), ветка и выбор в книге — как у бота (`--bottree`). Уровень — по среднему уровню героев.
- **Управление:**
  - наёмник следует за нанимателем;
  - команды, как у питомца из сессии 06 (если сделана): атаковать мою цель / защищать / стоять;
  - в рамке группы виден как обычный союзник, его можно лечить и баффать.
- **Снаряжение:** нанимателю можно отдать наёмнику вещь, если просто. Иначе — снаряжение по уровню автоматически.
- **Сила и ограничения:**
  - боссы и волны масштабируются по числу участников, наёмники считаются **с понижающим коэффициентом**;
  - в сети наёмников считает хост — это обычные герои-боты, без отдельного peer.
  - опыт наёмникам не нужен, но доля добычи — да. По правилам п. 2 наёмник не забирает вещи себе.
- Флаг `--hire=priest,warrior` для тестов.

## 2. Правила добычи

Хост выбирает в настройках партии:
- **Личная добыча** (по умолчанию для группы): каждый видит своё, вещи подобраны под его класс с перевесом, как в 07б.
- **«Нужно / Не откажусь / Отказаться»** — бросок кубиков для синего и выше, окно броска с таймером 20 с. Белое и зелёное — свободная добыча.
- **Свободная:** кто первый взял, тот и молодец — как сейчас.
- В соло правило не важно, всё твоё.
- **Объявления:** «Иван выиграл: Стальной меч медведя (Нужно, 87)». Журнал добычи партии — в итогах.

## 3. Трупы врагов с добычей (просьба пользователя)

- Труп врага **остаётся на земле** примерно 60 с (боссы — дольше), затем плавно исчезает. Трупы для некроманта из сессии 02 — те же.
- **Добыча внутри трупа.** Если с врага что-то выпало, над трупом мерцание или луч цвета лучшего качества внутри. ПКМ по трупу (или клавиша взаимодействия рядом) открывает окно добычи: взять по одному или «Взять всё».
- Золото подбирается автоматически при открытии.
- Пустые трупы не подсвечиваются.
- **Производительность:**
  - трупы — в системе мобов, без нод на каждый, анимация смерти замирает на последнем кадре;
  - при большом числе трупов сначала исчезают пустые и дальние;
  - лимит, например 150 трупов, — подбери по FPS.
- **Сеть:** что лежит в трупе, знает сервер. Клиенту при личной добыче приходит только его часть.

## 4. Проверка

- Соло-прогон с двумя наёмниками разных ролей до 10-й волны и босса: наёмники живы, лечат, танкуют.
- Сетевой прогон: все три правила добычи, броски, личная добыча у двух игроков разная.
- FPS на большой волне с трупами.
