# Дорожная карта Hero Siege

## Куда идём

Сейчас Hero Siege — это одна игра: осада замка. Дальше она станет **одним из режимов**. Классы, заклинания, таланты, предметы, враги и сеть будут общими, а поверх них появятся:

1. **Осада** (есть): волны с 1–4 сторон, замок, передышки.
2. **Осада с сохранением** (сессия 07): герой, его снаряжение и уровень сохраняются, враги сильнее с каждым походом.
3. **Подземелья для группы** (позже): вход, коридоры и залы, пачки мобов, боссы с механиками, добыча.
4. **Открытый мир** (далеко): локации, NPC, квесты, переходы между зонами.

Поэтому каждое изменение проверяем вопросом: **будет ли это работать вне осады?** Боссу, элитным мобам и способностям мобов не должно быть важно, что рядом стоит замок и идут волны.

## Архитектурные опоры

Их закладываем постепенно, в сессиях ниже.

| Опора | Что значит | Когда |
|---|---|---|
| Режим игры | `world.gd` разделён: общий мир (герои, мобы, бой, добыча) и **режим** `SiegeMode` (волны, замок, передышки, победа и поражение). Новый режим — это новый класс режима, а не правки world. | 01 |
| Фракции и встречи данными | Враги описаны фракциями: модели, способности, элитные аффиксы, боссы. Волна осады и пачка в подземелье собираются из одних и тех же описаний. | 02–03 |
| ИИ мобов по поведениям | Поведение моба (ближний, дальний, лекарь, призыватель, подрывник, босс-скрипт) задаётся данными. ИИ не привязан к «полосам». Полоса — лишь один из источников цели движения. | 02 |
| Способности мобов и боссов | Те же эффекты (`damage`, `dot`, `slow`, `freeze`…), что у героев, и те же зоны и снаряды из `spell_system`. Плюс телеграфы на земле. | 02–03 |
| Герой как сохраняемые данные | Класс, раса, уровень, опыт, таланты, выбор в книге заклинаний, снаряжение, аксессуары, сумка, золото и раскладка панели сериализуются в один словарь с версией формата. | 07 |
| Личность игрока | Стабильный идентификатор игрока, не peer id. На нём держатся переподключение, поздний вход и сохранения. | 07 |
| Горячий код на C++ | `mob_manager` уходит в GDExtension, когда контент мобов устоится. | 08 |

## Как запускать сессию

На рабочей машине, в папке проекта:

```
git pull
claude
```

Первое сообщение: `Выполни задание из docs/prompts/01-fundament-i-pravki.md`

Правила работы (без вопросов, решения в DECISIONS.md, отчёт, проверки) уже лежат в `CLAUDE.md`, повторять их не нужно.
