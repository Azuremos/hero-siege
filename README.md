# Hero Siege — осада замка

Кооперативная RPG-защита замка в духе карт Hero Siege из Warcraft 3, с видом от третьего лица и управлением как в World of Warcraft.
Движок — Godot 4.7.2, лежит в `C:\Users\abbas\Godot`.

## Запуск

- **Играть.bat** — запустить игру.
- **Открыть в редакторе.bat** — открыть проект в редакторе Godot. Там F5 запускает игру.

## Игра с друзьями через Radmin VPN

1. Все заходят в одну сеть Radmin VPN.
2. Хост нажимает «Создать игру (хост)». В лобби показан его адрес вида `26.x.x.x`.
3. Друзья вводят этот адрес и нажимают «Подключиться».
4. Хост нажимает «Начать осаду!». В отряде до 6 игроков.

При первом запуске хоста Windows спросит про брандмауэр — нужно **разрешить** доступ.
Используется порт UDP 7777.

У друзей должна быть та же версия игры — архив со страницы релиза (Godot уже внутри, ставить ничего не нужно, кроме Radmin VPN).

## Управление (как в WoW)

| Клавиша | Действие |
|---|---|
| W / S | вперёд / назад |
| A / D | поворот (с зажатой ПКМ — шаг вбок) |
| Q / E | шаг влево / вправо |
| ПКМ (зажать) | поворот камеры вместе с героем |
| ЛКМ (зажать) | осмотреться камерой |
| ЛКМ + ПКМ | бежать вперёд |
| Колесо мыши | приближение камеры |
| ЛКМ по существу | выбрать цель |
| ПКМ по врагу | атаковать |
| Tab | ближайший враг |
| 1–9, 0, −, = | панель 1 (12 ячеек) |
| Shift + 1–9, 0, −, = | панель 2 |
| N | таланты |
| P | книга заклинаний |
| C | персонаж, снаряжение и сумка |
| ПКМ по торговцу | открыть лавку |
| F1–F6 | выбрать участника группы |
| H | справка |
| Esc | отмена / меню |

**Лечение (Жрец, Паладин):** клик по рамке группы слева выбирает союзника.
Если навести курсор на рамку и нажать клавишу заклинания, лечение уйдёт этому союзнику, а текущая цель не изменится.

**Заклинания на землю** (Снежная буря, Барьер Света): после нажатия клавиши появляется прицел — ЛКМ ставит заклинание, ПКМ отменяет.

**Стены (Ледяная стена, Стена огня) рисуются мышью:** зажмите ЛКМ в начале стены и протяните до конца. Длина ограничена: лёд — до 14 м, огонь — до 16 м.
Простой клик ставит стену полной длины поперёк взгляда.

## Уровни, заклинания и таланты

**Открытие заклинаний.** Каждое заклинание класса открывается на своём уровне (от 1 до 11). Например, у Мага ледяная стена открывается на 7-м уровне.

**Заморозка.** Замороженный враг покрыт льдом, не двигается и не атакует (боссы — вдвое короче):
- Ледяная стрела и Снежная буря копят холод — на третьем попадании цель замерзает;
- Кольцо льда и Глубокая заморозка замораживают сразу.

**Баффы Паладина:**
- Благословение королей — +10% к здоровью, мане, урону и лечению на 10 минут;
- Гнев карателя — золотые крылья за спиной, +25% к урону и лечению на 20 сек.;
- Божественный защитник — вся группа рядом получает на 20% меньше урона.

**Баффы Жреца:**
- Слово силы: Стойкость — +15% к здоровью;
- Божественный дух — быстрее восполняется мана;
- Молитва исцеления — лечит всю группу рядом.

У каждого класса по 11 заклинаний. Свои баффы видны под портретом героя.

**Тайная магия Мага:** Чародейские стрелы (поток из 5 снарядов), Чародейский взрыв (волна вокруг себя), Скачок (телепорт на 15 м), Чародейский обстрел.
Закрытые ячейки на панели показывают замок и нужный уровень.

**Таланты (N)** — в стиле WotLK:
- 3 ветки на класс, 1 очко за каждый уровень начиная со 2-го.
- Каждый следующий ряд открывается после 3 очков, вложенных в ветку.
- Вершина ветки даёт новое заклинание. Оно само встаёт на свободную клавишу.
- Таланты можно бесплатно сбросить.

| Класс | Ветки | Заклинания вершин |
|---|---|---|
| Маг | Тайная магия, Огонь, Лёд | Чародейская мощь, Живая бомба, Глубокая заморозка |
| Паладин | Свет, Защита, Воздаяние | Частица Света, Щит мстителя, Божественная буря |
| Жрец | Послушание, Свет, Кара | Подавление боли, Оберегающий дух, Сияние небес |
| Воин | Оружие, Неистовство, Защита | Смертельный удар, Буйство, Ударная волна |

**Проки** — таланты, которые иногда дают усиленное или бесплатное заклинание. Ячейка такого заклинания на панели начинает светиться.

| Класс | Прок | Что даёт |
|---|---|---|
| Маг | Всплеск тайной магии | следующие Чародейские стрелы / Обстрел бесплатны, сильнее на 50% и без перезарядки |
| Маг | Огненная глыба | огненное заклинание может обрушить с неба глыбу: урон по области и горение |
| Маг | Ледяные пальцы | следующая Ледяная стрела или Глубокая заморозка — мгновенно, бесплатно и на 50% сильнее |
| Паладин | Священная кара | от автоатаки: следующий Свет небес или Правосудие — мгновенно и бесплатно |
| Паладин | Прилив Света | крит лечения делает следующий Свет небес мгновенным |
| Паладин | Печать мести | от автоатаки: взрыв Света вокруг паладина (ветка Защиты) |
| Паладин | Вызов Света | АоЕ-провокация в 1-м ряду Защиты |
| Жрец | Взятое взаймы время, Волна Света | быстрые и бесплатные лечение и Кара |
| Жрец | Звезда Света | от Кары и Священного огня: звезда падает на врагов и лечит союзников рядом |
| Воин | Внезапная смерть | Казнь доступна при любом здоровье цели и бесплатна |
| Воин | Прилив крови | после Жажды крови или Вихря — бесплатный и усиленный Удар героя |
| Воин | Возмездие | при получении удара — бесплатный и усиленный Удар грома |
| Воин | Вызывающий крик | АоЕ-провокация в ветке Защиты |

**Панель заклинаний** настраивается мышью, как в WoW:
- перетащите заклинание на другую ячейку — они поменяются местами;
- утащите заклинание за пределы панели — ячейка освободится;
- из книги заклинаний (P) можно поставить любое известное заклинание.

Раскладка запоминается отдельно для каждого класса.

## Интерфейс

- **Портрет героя** с уровнем, под ним — баффы и оставшееся время.
- **Две панели заклинаний.** Заклинания перетаскиваются между ними и из книги (P).
- **Подвижные рамки.** Esc → «Настроить интерфейс»: рамки (герой, цель, группа, обе панели, полоса произнесения, осада) двигаются мышью. Группа и панель 2 переключаются между горизонтальной и вертикальной раскладкой. Расположение сохраняется.
- **Горячие клавиши** меняются: Esc → «Горячие клавиши» или кнопка в главном меню.
- **Просмотр талантов** любого класса — кнопка «Таланты класса» в главном меню. Там можно спланировать раскладку на 30-м уровне.

## Длительность осады

При выборе героя можно задать 1, 2, 3, 4, 5, 10, 20, 30 или 50 волн либо **бесконечную осаду**.
В быстрых партиях (1–4 волны) последняя волна заканчивается боссом. После 20-й волны враги продолжают усиливаться.

**Передышки.** После каждой 3-й волны новая не начнётся, пока не добиты все враги.
Затем отдых — 60 секунд (при выборе героя можно поставить 30, 60 или 90): здоровье и мана восполняются в 8 раз быстрее. Хост может начать волну раньше кнопкой «Начать волну сейчас».

**Направления атаки** — с какого числа сторон идут враги:
- 1 — только юг (там появляются герои);
- 2 — юг и восток;
- 3 — юг, восток и запад;
- 4 — со всех сторон.

Длительность, передышку и направления выбирает хост, и они действуют для всех игроков.

## Характеристики героя

Урон и лечение растут с уровнем: +5% за каждый уровень. Кроме того, у героя есть **атрибуты**, они растут с каждым уровнем и дают бонусы от снаряжения.

| Атрибут | Что даёт |
|---|---|
| Сила | +1% к урону оружием и физическими приёмами за единицу |
| Ловкость | шанс крита и немного брони |
| Выносливость | +10 к здоровью за единицу |
| Интеллект | +15 к мане и +1% к силе заклинаний за единицу |
| Дух | восполнение маны и здоровья |

Все характеристики, снаряжение и сумка — в окне персонажа (**C** или кнопка «Персонаж» рядом с панелью).

## Воин

Боец ближнего боя и танк. Вместо маны у него **ярость**: она копится от ударов по врагам и от полученного урона, а вне боя постепенно угасает.

- **Оружие** — сильные одиночные удары, Казнь, кровотечения, Смертельный удар.
- **Неистовство** — быстрые атаки, Вихрь, Жажда крови. Талант **«Бой двумя оружиями»** позволяет взять второе оружие в левую руку (60% его характеристик).
- **Защита** — щит, Провокация, Вызывающий крик (агро на всех врагов рядом), Глухая оборона, Ударная волна.

## Лавки, снаряжение и добыча

На площади у замка стоят два торговца, ПКМ по торговцу открывает лавку:
- **Кузнец Торвальд** — оружие и доспехи шести уровней качества (от медных до драконьих);
- **Алхимик Мирра** — зелья здоровья и маны, эликсиры силы, стойкости и мудрости.

**Снаряжение:** 7 ячеек — оружие, левая рука (для воина-неистовства), шлем, доспех, сапоги, кольцо, амулет. Оружие доступно только своим классам.

**Сумка** на 20 ячеек:
- ЛКМ — надеть предмет или выпить зелье;
- ПКМ у открытой лавки — продать за 25% цены;
- зелья можно перетащить на панель заклинаний, у них общая перезарядка 30 сек.

**Добыча.** С врагов иногда падают сундуки с предметами и зелья. Чем дальше волна, тем лучше вещи. Луч над добычей показывает качество, а подобрать её можно, просто подойдя. Боссы всегда оставляют две вещи и зелье. Предмет может оказаться для любого класса — ненужное продайте.

## Главное меню и настройки

- **Одиночная игра** и **Сетевая игра** — выбор героя, длительности осады и направлений атаки.
- **Таланты классов** — просмотр и планирование талантов любого класса.
- **Настройки** (в меню и в игре через Esc):
  - громкость общая, музыки и эффектов;
  - полный экран, вертикальная синхронизация, качество теней;
  - раскладка группы и панели 2, сброс положения рамок, горячие клавиши.
- **Музыка** своя для меню, боя и передышки, переключается плавно.

Дороги к замку и площадь перед ним вымощены брусчаткой.

## Оптимизация под i7-950 + RX 580

- Мобы обрабатываются одной системой без физики. Сервер считает их 20 раз в секунду, поиск соседей идёт по сетке.
- Части тела каждого скелета склеены в один меш, деревья и камни рисуются через MultiMesh.
- Тени есть только у ближних мобов. Дальние мобы реже обновляют анимацию.
- Эффекты считаются на видеокарте (GPU-частицы).

Тест: 217 мобов на экране — 54–60 FPS. Если игра тормозит, выключите тени в настройках.

## Тестовый запуск из командной строки

```
Godot_v4.7.2-stable_win64_console.exe --path . -- --solo --class=mage --bot --fastwaves --quit-after=60
```

Параметры:

| Параметр | Что делает |
|---|---|
| `--class=` | `mage` / `paladin` / `priest` / `warrior` |
| `--race=` | `human` / `dwarf` / `elf` / `draenei` |
| `--host --autostart=2` | хост, игра стартует при 2 игроках |
| `--join=IP` | подключиться к хосту |
| `--bot` | героем управляет бот |
| `--bottree=N` | ветка талантов бота (0–2) |
| `--startwave=N` | начать с волны N |
| `--vfxtest` | показать все эффекты |
| `--level=N` | сразу дать герою уровень N (бот сам изучит таланты) |
| `--gold=N` | дать золото и набор тестовых вещей |
| `--equip=T` | на T-й секунде надеть все вещи из сумки |
| `--lootrate=X` | шанс добычи с врага (0–1) |
| `--proclog`, `--procall` | писать проки в лог / проки срабатывают всегда |
| `--autotest=meteor` | показать автозаклинание (`meteor`, `holy_star`, `divine_burst`) |
| `--waves=N` | число волн в партии (0 — бесконечно) |
| `--lanes=N` | число направлений атаки (1–4) |
| `--breaktime=N` | длительность передышки: `30` / `60` / `90` сек. |

Тестовые запуски с параметрами не меняют ваши сохранённые настройки и раскладку панели.
