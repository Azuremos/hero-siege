# Hero Siege — осада замка

Кооперативная RPG-защита замка в духе карт Hero Siege из Warcraft 3, с видом от третьего лица и управлением как в World of Warcraft.
Движок — Godot 4.7.2, лежит в `C:\Users\abbas\Godot`.

## Запуск

- **Играть.bat** — запустить игру.
- **Открыть в редакторе.bat** — открыть проект в редакторе Godot. Там F5 запускает игру.

## Игра с друзьями через Radmin VPN

1. Все заходят в одну сеть Radmin VPN.
2. Хост нажимает «Создать игру (хост)». В лобби показан его адрес вида `26.x.x.x`.
3. Друзья вводят этот адрес и нажимают «Подключиться».
4. Хост нажимает «Начать осаду!». В отряде до 6 игроков.

При первом запуске хоста Windows спросит про брандмауэр — нужно **разрешить** доступ.
Используется порт UDP 7777.

У друзей должна быть та же версия игры — архив со страницы релиза (Godot уже внутри, ставить ничего не нужно, кроме Radmin VPN).
Версия видна в правом нижнем углу главного меню и в лобби напротив каждого игрока. Если версии не совпадают, игра не пустит в лобби и напишет, какая версия у хоста.

**Лечение (Жрец, Паладин):** клик по рамке группы слева выбирает союзника.
Если навести курсор на рамку и нажать клавишу заклинания, лечение уйдёт этому союзнику, а текущая цель не изменится.

**Заклинания на землю** (Снежная буря, Барьер Света): после нажатия клавиши появляется прицел — ЛКМ ставит заклинание, ПКМ отменяет.

**Стены (Ледяная стена, Стена огня) рисуются мышью:** зажмите ЛКМ в начале стены и протяните до конца. Длина ограничена: лёд — до 14 м, огонь — до 16 м.
Простой клик ставит стену полной длины поперёк взгляда.

## Уровни, заклинания и таланты

**Открытие заклинаний.** Каждое заклинание класса открывается на своём уровне (от 1 до 11). Например, у Мага ледяная стена открывается на 7-м уровне.

**Заморозка.** Замороженный враг покрыт льдом, не двигается и не атакует (боссы — вдвое короче):
- Ледяная стрела и Снежная буря копят холод — на третьем попадании цель замерзает;
- Кольцо льда и Глубокая заморозка замораживают сразу.

**Баффы Паладина:**
- Благословение королей — +10% к здоровью, мане, урону и лечению на 10 минут;
- Гнев карателя — золотые крылья за спиной, +25% к урону и лечению на 20 сек.;
- Божественный защитник — вся группа рядом получает на 20% меньше урона.

**Баффы Жреца:**
- Слово силы: Стойкость — +15% к здоровью;
- Божественный дух — быстрее восполняется мана;
- Молитва исцеления — лечит всю группу рядом.

У каждого класса по 11 заклинаний. Свои баффы видны под портретом героя.

**Тайная магия Мага:** Чародейские стрелы (поток из 5 снарядов), Чародейский взрыв (волна вокруг себя), Скачок (телепорт на 15 м), Чародейский обстрел.
Закрытые ячейки на панели показывают замок и нужный уровень.

**Таланты (N)** — в стиле WotLK:
- 3 ветки на класс, 1 очко за каждый уровень начиная со 2-го.
- Каждый следующий ряд открывается после 3 очков, вложенных в ветку.
- Вершина ветки даёт новое заклинание. Оно само встаёт на свободную клавишу.
- Таланты можно бесплатно сбросить.

| Класс | Ветки | Заклинания вершин |
|---|---|---|
| Маг | Тайная магия, Огонь, Лёд | Чародейская мощь, Живая бомба, Глубокая заморозка |
| Паладин | Свет, Защита, Воздаяние | Частица Света, Щит мстителя, Божественная буря |
| Жрец | Послушание, Свет, Кара | Подавление боли, Оберегающий дух, Сияние небес |
| Воин | Оружие, Неистовство, Защита | Смертельный удар, Буйство, Ударная волна |

**Проки** — таланты, которые иногда дают усиленное или бесплатное заклинание. По ячейке такого заклинания бегут светящиеся точки, а по бокам от героя появляются крупные иконки заклинания со звуком. Оба сигнала выключаются в настройках, а центральный двигается в настройке интерфейса.

|---|---|---|
| Маг | Всплеск тайной магии | следующие Чародейские стрелы / Обстрел бесплатны, сильнее на 50% и без перезарядки |
| Маг | Огненная глыба | огненное заклинание может обрушить с неба глыбу: урон по области и горение |
| Маг | Ледяные пальцы | следующая Ледяная стрела или Глубокая заморозка — мгновенно, бесплатно и на 50% сильнее |
| Паладин | Священная кара | от автоатаки: следующий Свет небес или Правосудие — мгновенно и бесплатно |
| Паладин | Прилив Света | крит лечения делает следующий Свет небес мгновенным |
| Паладин | Печать мести | от автоатаки: взрыв Света вокруг паладина (ветка Защиты) |
| Паладин | Вызов Света | АоЕ-провокация в 1-м ряду Защиты |
| Жрец | Взятое взаймы время, Волна Света | быстрые и бесплатные лечение и Кара |

| Воин | Вызывающий крик | АоЕ-провокация в ветке Защиты |

**Панель заклинаний** настраивается мышью, как в WoW:
- перетащите заклинание на другую ячейку — они поменяются местами;
- утащите заклинание за пределы панели — ячейка освободится;
- из книги заклинаний (P) можно поставить любое известное заклинание.

Раскладка запоминается отдельно для каждого класса.

## Интерфейс

- **Портрет героя** с уровнем, под ним — баффы и оставшееся время.
- **Две панели заклинаний.** Заклинания перетаскиваются между ними и из книги (P). Перезарядка — тёмные «часы» с секундами, общая перезарядка (ГКД) — светлая тень со стрелкой на всех ячейках.
- **Рамка цели** показывает эффекты на враге: свои крупнее и ярче, чужие мельче, холод со стаками «1/3», время и подсказку. Свои эффекты видны и над головой цели.
- **Выбранный союзник** выделен золотой обводкой в рамке группы и кольцом под ним; рамка под курсором — голубая, туда уйдёт лечение «по наведению». Дебаффы союзников — с красной окантовкой.
- **Счётчик урона и лечения (K)** — как Details в WoW: урон, лечение (перелечивание бледнее), полученный урон, смерти; текущий бой, прошлая волна, вся партия. Наведите на строку — разбивка по заклинаниям. Окно тянется за угол.
- **Рейдовые метки и пинги** — Ctrl+1…8 или ПКМ по рамке цели; Alt+ЛКМ — пинг. Хост может оставить метки только себе (флажок на экране сетевой игры).
- **Подвижные рамки.** Esc → «Настроить интерфейс» или кнопка «Настроить интерфейс» в главном меню (предпросмотр с группой из 6, целью и примером данных): рамки (герой, цель, группа, обе панели, полоса произнесения, панель режима, сигнал прока, счётчик) двигаются мышью. Группа и панель 2 переключаются между горизонтальной и вертикальной раскладкой. Расположение сохраняется.
- **Горячие клавиши** меняются: Esc → «Горячие клавиши» или кнопка в главном меню.
- **Просмотр талантов** любого класса — кнопка «Таланты класса» в главном меню. Там можно спланировать раскладку на 30-м уровне.

## Враги: четыре фракции

Каждая фракция идёт со своей стороны света и выходит из своего логова. Направления открываются в порядке юг → восток → запад → север: при одном направлении — только нежить, при четырёх — все. Хост может выбрать «случайно» или «одна фракция везде».

| Сторона | Фракция | Логово | Массовка | Тяжёлый | Быстрый | Дальний бой | Поддержка | Особый |
|---|---|---|---|---|---|---|---|---|
| Юг | Нежить | кладбище со склепом | скелет-прислужник | скелет-воин | скелет-разбойник | скелет-маг, костяной арбалетчик | некромант (поднимает мёртвых) | вурдалак (пожирает трупы), банши (вой — страх) |
| Восток | Орки | военный лагерь | рубака | берсерк (боевое безумие) | налётчик (налёт со замедлением) | метатель топоров | шаман (цепная молния, жажда крови), вождь-барабанщик (аура скорости) | — |
| Запад | Демоны | огненная яма с порталом | бес (огненные стрелы) | страж Скверны | гончая Скверны (выжигает ману) | — | суккуба (соблазн — оглушение) | инфернал (падает с неба, оглушает) |
| Север | Гоблины и огры | лагерь из хлама у шахты | гоблин-стрелок | огр-громила (сокрушение, отбрасывание) | гоблин-вор (крадёт золото и убегает) | — | гоблин-техник (мины), огр-маг (щит, ускорение) | гоблин-подрывник (взрывается у стены или героя) |

**Касты врагов и прерывания.** Над головой и под рамкой цели видна полоса произнесения: жёлтая — заклинание можно сбить, серая со щитом — нельзя. У каждого класса есть прерывание (с 3-го уровня, не тратит общую перезарядку): маг — Антимагия, воин — Зуботычина, паладин — Укор, жрец — Безмолвие. Сбитое заклинание блокирует у врага эту школу на 4 сек. Оглушение и заморозка тоже сбивают каст. Опасные удары сначала показываются на земле красным кругом или конусом — успейте выйти.

**Контроль на героях.** Враги могут напугать (герой бежит прочь), оглушить, очаровать, наложить немоту, отбросить и выжечь ману. Это видно в баффах рамки героя и группы.

**Волны** собираются из бюджета очков: он растёт с номером волны и числом игроков. Бывают особые волны: «Разведка» (много быстрых), «Осада» (тяжёлые и подрывники), «Колдовская» (много поддержки). На каждой 5-й волне у нежити выходит босс, у остальных фракций — чемпион.

**Элитные враги** (с 4-й волны, чаще к поздним) крупнее, с цветной аурой и золотым именем. Здоровье ×3,5, награда ×4, вещь получше. У них 1–3 аффикса:

| Аффикс | Что делает |
|---|---|
| Бронированный | броня выше на 35% |
| Быстрый | бегает на 40% и бьёт на 25% быстрее |
| Вампирический | лечится на 30% нанесённого урона |
| Взрывной | взрывается через 1,5 сек. после смерти — уйдите из круга |
| Отражающий | возвращает 20% урона нападающему |
| Вдохновляющий | союзники рядом сильнее и быстрее |
| Призыватель | зовёт подмогу (можно сбить) |
| Огненный след | оставляет горящую землю |
| Неудержимый | не поддаётся контролю, кроме замедления |

Облики орков, демонов, гоблинов и огров пока временные — перекрашенные модели героев KayKit.

## Длительность осады

При выборе героя можно задать 1, 2, 3, 4, 5, 10, 20, 30 или 50 волн либо **бесконечную осаду**.
В быстрых партиях (1–4 волны) последняя волна заканчивается боссом. После 20-й волны враги продолжают усиливаться.

**Передышки.** После каждой 3-й волны новая не начнётся, пока не добиты все враги.
Затем отдых — 60 секунд (при выборе героя можно поставить 30, 60 или 90): здоровье и мана восполняются в 8 раз быстрее. Хост может начать волну раньше кнопкой «Начать волну сейчас».

**Направления атаки** — с какого числа сторон идут враги:
- 1 — только юг (там появляются герои);
- 2 — юг и восток;
- 3 — юг, восток и запад;
- 4 — со всех сторон.

Длительность, передышку и направления выбирает хост, и они действуют для всех игроков.

## Характеристики героя

Урон и лечение растут с уровнем: +5% за каждый уровень. Кроме того, у героя есть **атрибуты**, они растут с каждым уровнем и дают бонусы от снаряжения.

| Атрибут | Что даёт |
|---|---|
| Сила | +1% к урону оружием и физическими приёмами за единицу |
| Ловкость | шанс крита и немного брони |
| Выносливость | +10 к здоровью за единицу |
| Интеллект | +15 к мане и +1% к силе заклинаний за единицу |
| Дух | восполнение маны и здоровья |

Все характеристики, снаряжение и сумка — в окне персонажа (**C** или кнопка «Персонаж» рядом с панелью).

## Мана и перезарядки

- **Мана заканчивается.** Стоимость заклинаний растёт с уровнем — это доля базового запаса маны класса, как в WoW. Интеллект со снаряжения, эликсиры и таланты на запас маны дают реальный выигрыш.
- **Правило 5 секунд.** Вне боя мана восполняется быстро (полный запас примерно за 25 сек.), а 5 сек. после траты маны — только на 30%. Дух, эликсир мудрости, Божественный дух и таланты ускоряют восполнение, зелья маны возвращают сразу. В передышке — в 8 раз быстрее.
- Маг 20-го уровня на непрерывных массовых заклинаниях опустошается примерно за 40 сек., на одиночной цели — примерно за 2 минуты. Лекари при активном лечении группы тоже упираются в ману. Ярость воина не менялась.
- **Перезарядки** по ярусам: заполнитель без перезарядки, ротация 4–10 сек., площадь 8–20, контроль 20–45, большие способности 60–180, последний шанс 180–300. Например: Ледяная стена — 30 сек., Живая бомба — 6, Божественный щит — 180, Возложение рук — 300, Оберегающий дух — 180. Подробно — `docs/design/cooldowns.md`.
- **Слово силы: Щит** нельзя снова повесить на ту же цель 12 сек. — «Ослабленная душа».

## Воин

Боец ближнего боя и танк. Вместо маны у него **ярость**: она копится от ударов по врагам и от полученного урона, а вне боя постепенно угасает.

- **Оружие** — сильные одиночные удары, Казнь, кровотечения, Смертельный удар.
- **Неистовство** — быстрые атаки, Вихрь, Жажда крови. Талант **«Бой двумя оружиями»** позволяет взять второе оружие в левую руку (60% его характеристик).
- **Защита** — щит, Провокация, Вызывающий крик (агро на всех врагов рядом), Глухая оборона, Ударная волна.

## Лавки, снаряжение и добыча

На площади у замка стоят два торговца, ПКМ по торговцу открывает лавку:
- **Кузнец Торвальд** — оружие и доспехи шести уровней качества (от медных до драконьих);
- **Алхимик Мирра** — зелья здоровья и маны, эликсиры силы, стойкости и мудрости.

**Снаряжение:** 7 ячеек — оружие, левая рука (для воина-неистовства), шлем, доспех, сапоги, кольцо, амулет. Оружие доступно только своим классам.

**Сумка** на 20 ячеек:
- ЛКМ — надеть предмет или выпить зелье;
- ПКМ у открытой лавки — продать за 25% цены;
- зелья можно перетащить на панель заклинаний, у них общая перезарядка 30 сек.

**Добыча.** С врагов иногда падают сундуки с предметами и зелья. Уровень вещи подбирается по уровню героев рядом: почти всё, что выпало, можно надеть сразу или через 1–2 уровня; номер волны ограничивает уровень сверху. В лавке вещи не по уровню видны, но приглушены. Луч над добычей показывает качество, а подобрать её можно, просто подойдя. Боссы всегда оставляют две вещи и зелье. Предмет может оказаться для любого класса — ненужное продайте.

## Главное меню и настройки

- **Одиночная игра** и **Сетевая игра** — выбор героя, длительности осады и направлений атаки.
- **Таланты классов** — просмотр и планирование талантов любого класса.
- **Настройки** (в меню и в игре через Esc):
  - громкость общая, музыки и эффектов;
  - полный экран, вертикальная синхронизация, качество теней;
  - раскладка группы и панели 2, сброс положения рамок, горячие клавиши.
- **Музыка** своя для меню, боя и передышки, переключается плавно.

Дороги к замку и площадь перед ним вымощены брусчаткой.

## Что уже есть

- **4 класса по 11 заклинаний:**
  - **Маг:** лёд, огонь и тайная магия. Стены рисуются мышью, есть заморозка и Огненная глыба.
  - **Паладин:** Свет в атаке и защите, лечение, благословения.
  - **Жрец:** лечение со временем, щиты, Барьер Света на земле, Круг исцеления.
  - **Воин:** ближний бой и танк, ярость, бой двумя оружиями.
- **4 расы с бонусами и обликом:** человек, дворф, высший эльф, дреней.
- **Уровни 1–30.** Опыт за убийства делится между всеми героями поблизости.
- **Осада:**
  - 1–4 направления атаки, от 1 волны до бесконечной осады;
  - боссы каждые 5 волн;
  - сложность растёт с номером волны и числом игроков;
  - передышки каждые 3 волны.
- **Экономика:** золото, две лавки, 7 ячеек снаряжения, сумка, зелья, добыча с врагов по уровню героев.
- **Мана и перезарядки:** стоимость растёт с уровнем, правило 5 секунд, ярусы перезарядок.
- **Интерфейс для группы:** счётчик урона и лечения, эффекты на цели, выделение союзника, рейдовые метки и пинги, заметные проки, настройка рамок прямо из главного меню.
- **Враги:** 4 фракции с 25 видами врагов, способности и касты, прерывания, элитные с аффиксами, логова на карте.
- **Карта:** деревья, рощи, камни и декор непроходимы.
- **Мультиплеер:** хост считает бой, клиенты получают сжатые снимки. Версия проверяется при подключении. Одиночная игра не занимает сетевой порт.
- **Режимы игры** — отдельный слой (`scripts/modes/`): сейчас осада и предпросмотр интерфейса, дальше — подземелья и открытый мир (см. `docs/ROADMAP.md`).
- **Звук и музыка:**
  - заклинания всех школ магии;
  - удары, стук костей, рёв боссов;
  - колокол начала волны;
  - мелодии нового уровня и конца игры;
  - фоновая музыка меню, боя и передышки.

## Оптимизация под i7-950 + RX 580

- Мобы обрабатываются одной системой без физики. Сервер считает их 20 раз в секунду, поиск соседей идёт по сетке.
- Части тела каждого скелета склеены в один меш, деревья и камни рисуются через MultiMesh.
- Тени есть только у ближних мобов. Дальние мобы реже обновляют анимацию.
- Эффекты считаются на видеокарте (GPU-частицы).

Тест (сессия 02, окно 1600×900, герой в гуще боя): волна 20 со всех сторон — 60 FPS при 70–85 мобах; бесконечная осада с 80-й волны — 60 FPS до ~130 мобов, ~50 при 160 и ~40 при 190 (так же, как в v0.5). Если игра тормозит, выключите тени в настройках.

## Тестовый запуск из командной строки

```
Godot_v4.7.2-stable_win64_console.exe --path . -- --solo --class=mage --bot --fastwaves --quit-after=60
```

Параметры:

| Параметр | Что делает |
|---|---|
| `--class=` | `mage` / `paladin` / `priest` / `warrior` |
| `--race=` | `human` / `dwarf` / `elf` / `draenei` |
| `--host --autostart=2` | хост, игра стартует при 2 игроках |
| `--join=IP` | подключиться к хосту |
| `--bot` | героем управляет бот |
| `--bottree=N` | ветка талантов бота (0–2) |
| `--startwave=N` | начать с волны N |
| `--vfxtest` | показать все эффекты |
| `--level=N` | сразу дать герою уровень N (бот сам изучит таланты) |
| `--gold=N` | дать золото и набор тестовых вещей |
| `--equip=T` | на T-й секунде надеть все вещи из сумки |
| `--lootrate=X` | шанс добычи с врага (0–1) |
| `--proclog`, `--procall` | писать проки в лог / проки срабатывают всегда |
| `--autotest=meteor` | показать автозаклинание (`meteor`, `holy_star`, `divine_burst`) |
| `--waves=N` | число волн в партии (0 — бесконечно) |
| `--lanes=N` | число направлений атаки (1–4) |
| `--breaktime=N` | длительность передышки: `30` / `60` / `90` сек. |
| `--port=N` | порт сетевой игры (чтобы тесты не мешали запущенной копии) |
| `--fakeversion=X` | притвориться версией X (проверка отказа по версии) |
| `--manalog` | мана, расход, урон и лечение раз в 5 сек. и итог за минуту |
| `--godmode` | здоровье героя не падает ниже 35% (лекарю есть кого лечить) |
| `--mobhp=X` | враги живут в X раз дольше (бой без пауз) |
| `--botspells=a,b` | бот пользуется только этими заклинаниями |
| `--castlog` | писать отказы сервера на просьбы о заклинаниях |
| `--post=x,z` | пост бота (с `--chasedebug` герой переносится туда) |
| `--chasedebug` | счётчик «беготни» мобов: погони, сбросы, повторные захваты |
| `--lanedebug` | сколько мобов на каждой полосе |
| `--walltest`, `--walldmg` | поставить стены и показать стадии трещин |
| `--focustest` | клик по кнопкам HUD, затем Пробел: герой прыгает, окна не открываются |
| `--lootsim` | доля выпавших вещей, которые можно надеть (было / стало) |
| `--giveproc=ключ` | выдать прок (например `fingers_of_frost`) |
| `--targetally`, `--fxdemo=T` | союзник в цели / эффекты на ближайшем враге |
| `--meterlog` | итоги счётчика урона в конце |
| `--marktest=T`, `--markshost` | поставить метки и пинги / метки только у хоста |
| `--uipreview` | открыть предпросмотр интерфейса |
| `--faction=undead/orcs/demons/goblins` | все стороны — одна фракция |
| `--elite=1`, `--affix=<id>` | каждый моб элитный / у элитных этот аффикс |
| `--mobtest=<тип|фракция>` (`--near`) | поставить врага (или всю фракцию) перед героем |
| `--casttest` | рядом стоит враг, который бесконечно произносит сбиваемое заклинание |

Тестовые запуски с параметрами не меняют ваши сохранённые настройки, раскладку панели и рамок.

Отдельно: `godot --headless --path . -s res://tools/loot_sim.gd` — симуляция уровня выпадающих вещей.
